🌐 Jaringan Komputer

Konsep dasar jaringan komputer: jenis jaringan, topologi, dan mekanisme komunikasi data.

Jenis-Jenis Jaringan Komputer

01

Topologi Jaringan

02

Topologi jaringan adalah pola/struktur bagaimana perangkat (node) saling terhubung satu sama lain dalam sebuah jaringan.

⭐ Star (Bintang)

Semua node terhubung ke satu perangkat pusat (switch/hub). Keunggulan: jika satu node mati, jaringan lain tidak terganggu. Kelemahan: jika switch pusat mati, seluruh jaringan lumpuh.

🚌 Bus

Semua node terhubung ke satu kabel utama (backbone). Murah dan mudah dipasang, namun jika kabel utama putus semua komunikasi terhenti. Tidak efisien untuk jaringan besar.

💍 Ring (Cincin)

Node terhubung membentuk lingkaran tertutup. Data bergerak searah (unidirectional) atau dua arah. Menggunakan metode token passing untuk mengatur giliran pengiriman data.

🕸️ Mesh (Jaring)

Setiap node terhubung langsung ke semua node lain. Sangat andal dan toleran terhadap kerusakan, namun biaya kabel dan instalasi sangat mahal. Digunakan di infrastruktur kritis.

🌳 Tree (Pohon)

Kombinasi topologi Star dan Bus. Terdapat root node dengan cabang-cabang berhirarki. Mudah dikembangkan dan dikelola, namun bergantung pada backbone utama.

🔀 Hybrid

Kombinasi dua atau lebih topologi (misal Star + Ring). Fleksibel dan disesuaikan kebutuhan. Umumnya dipakai di jaringan besar seperti kampus atau perusahaan multinasional.

Mekanisme Token Passing

03

Apa itu Token Passing?

Token Passing adalah metode akses media (MAC) di mana sebuah token (paket data kecil berupa sinyal kontrol) bersirkulasi di antara node-node dalam jaringan. Hanya node yang memegang token yang berhak mengirimkan data. Setelah selesai, token diteruskan ke node berikutnya.

1

Token dihasilkan

Sebuah token bebas (free token) dilepaskan ke jaringan oleh monitor station atau node yang mengontrol jaringan.

2

Node menangkap token

Ketika sebuah node ingin mengirim data, ia menunggu hingga token bebas tiba, lalu menangkapnya dan mengubahnya menjadi token sibuk (busy token).

3

Data dikirimkan

Node yang memegang token mengirimkan frame data. Frame berisi alamat tujuan, data, dan informasi kontrol.

4

Penerima mengambil data

Node tujuan menyalin data ke buffer-nya dan menandai frame sebagai "sudah diterima", kemudian frame diteruskan kembali ke pengirim.

5

Token dilepaskan

Pengirim melepaskan token bebas baru ke jaringan, memberikan kesempatan kepada node berikutnya untuk mengirim data.

Keunggulan Token Passing

  • Tidak ada collision (tabrakan data) — deterministik
  • Setiap node mendapat giliran yang adil (fair access)
  • Performa stabil bahkan saat jaringan padat
  • Umum digunakan pada topologi Ring (Token Ring IEEE 802.5)

📊 Analisis Data

Proses mengubah data mentah menjadi informasi yang berguna melalui preprocessing, visualisasi, dan analitik.

Tahapan Preprocessing Data

01

Preprocessing adalah proses mempersiapkan data mentah sebelum dianalisis atau digunakan untuk pelatihan model machine learning. Data mentah sering kali tidak sempurna — bisa jadi kotor, tidak konsisten, atau tidak lengkap.

1

Data Cleaning (Pembersihan Data)

Proses menangani data yang tidak sempurna: mengisi nilai kosong (missing values), menghapus duplikat, mengoreksi kesalahan penulisan (typo), dan menghilangkan outlier yang ekstrem. Contoh: mengisi kolom usia yang kosong dengan rata-rata (mean imputation).

2

Data Integration (Integrasi Data)

Menggabungkan data dari berbagai sumber (database berbeda, file Excel, API) menjadi satu dataset yang konsisten. Menangani masalah redundansi dan konflik antar sumber data. Contoh: JOIN tabel transaksi dengan tabel pelanggan.

3

Data Transformation (Transformasi Data)

Mengubah format atau skala data agar sesuai untuk analisis. Termasuk: normalisasi (0–1), standardisasi (z-score), encoding kategorik (one-hot, label encoding), dan agregasi (merangkum data harian menjadi mingguan).

4

Data Reduction (Reduksi Data)

Mengurangi jumlah dimensi atau ukuran dataset tanpa kehilangan informasi penting. Teknik: PCA (Principal Component Analysis), sampling, binning, dan feature selection. Tujuannya meningkatkan efisiensi analisis dan mengurangi kompleksitas.

Visualisasi Data

02

Mengapa Visualisasi Penting?

Manusia memproses informasi visual 60.000× lebih cepat daripada teks. Visualisasi memudahkan menemukan pola, tren, outlier, dan korelasi yang sulit terlihat dari tabel angka biasa.

03

Google Colaboratory adalah platform cloud gratis dari Google untuk menulis dan menjalankan kode Python langsung di browser tanpa instalasi. Mendukung GPU/TPU gratis, sangat populer untuk data science dan machine learning.

⌨️ Dasar Pemrograman C++

Fondasi pemrograman: pseudocode, flowchart, tipe data, operator, dan logika percabangan.

Struktur Pseudocode

01

Apa itu Pseudocode?

Pseudocode adalah deskripsi algoritma menggunakan bahasa semi-formal yang mirip bahasa manusia. Bukan kode sungguhan, melainkan rancangan logika yang mudah dipahami sebelum diterjemahkan ke bahasa pemrograman.

Struktur pseudocode terdiri dari 3 bagian utama:

J

Judul (Header)

Nama program dan tujuannya. Biasanya ditulis di baris pertama. Contoh: PROGRAM HitungLuasSegitiga

D

Deklarasi (Declaration)

Mendefinisikan semua variabel, konstanta, dan tipe data yang akan digunakan. Contoh: DEKLARASI alas, tinggi, luas : REAL

I

Implementasi (Body)

Langkah-langkah instruksi algoritma (input, proses, output). Dimulai dengan MULAI dan diakhiri SELESAI. Berisi semua logika program.

pseudocode · HitungLuasSegitiga 
PROGRAM HitungLuasSegitiga

DEKLARASI
  alas, tinggi, luas : REAL

IMPLEMENTASI
  MULAI
    TULIS("Masukkan alas: ")
    BACA(alas)
    TULIS("Masukkan tinggi: ")
    BACA(tinggi)
    luas ← (1/2) * alas * tinggi
    TULIS("Luas = ", luas)
  SELESAI

Tentang Tipe Data CHAR

Tipe char menyimpan satu karakter ASCII dalam tanda kutip tunggal. Setiap karakter memiliki nilai numerik (kode ASCII). Contoh: 'A' = 65, 'a' = 97, '0' = 48. Char juga bisa digunakan untuk menyimpan angka kecil (−128 hingga 127).

Logika Percabangan (If-Else)

05

Konsep Percabangan

Percabangan memungkinkan program mengambil keputusan berbeda berdasarkan kondisi yang dievaluasi. Jika kondisi bernilai TRUE, blok pertama dieksekusi; jika FALSE, blok else (jika ada) yang dieksekusi.

C++ · if / if-else / if-else-if 
// 1. IF sederhana
if (nilai >= 75) {
    cout << "Lulus";
}

// 2. IF-ELSE
if (nilai >= 75) {
    cout << "Lulus";
} else {
    cout << "Tidak Lulus";
}

// 3. IF-ELSE-IF (bertingkat)
if (nilai >= 90) {
    cout << "A";
} else if (nilai >= 80) {
    cout << "B";
} else if (nilai >= 70) {
    cout << "C";
} else {
    cout << "D";
}

// 4. Nested IF (if bersarang)
if (umur >= 17) {
    if (memilikiKTP == true) {
        cout << "Boleh memilih";
    } else {
        cout << "Tidak punya KTP";
    }
} else {
    cout << "Belum cukup umur";
}

Tips Percabangan

  • Selalu gunakan tanda kurung kurawal {} meskipun satu baris, agar kode lebih aman
  • Operator perbandingan: == (sama dengan), != (tidak sama), < > <= >=
  • Jangan tertukar antara = (assignment) dan == (perbandingan)
  • Untuk kondisi yang banyak dengan satu variabel, pertimbangkan menggunakan switch-case

Detail Setiap Generasi

02

🔴 Generasi Pertama — Tabung Vakum

1940 – 1959 · ENIAC, UNIVAC, IBM 701

Menggunakan ribuan tabung vakum (vacuum tube) sebagai komponen elektronik utama. Ukurannya sangat besar (memenuhi satu ruangan penuh), menghasilkan panas yang luar biasa, boros listrik, dan sering mengalami kerusakan. Pemrograman dilakukan dengan kabel yang dicolokkan secara manual (patch panel) atau kartu berlubang (punched cards). Input/output sangat terbatas. ENIAC (1945) memiliki sekitar 18.000 tabung vakum.

🟠 Generasi Kedua — Transistor

1959 – 1965 · IBM 1401, UNIVAC 1108

Transistor menggantikan tabung vakum. Ukuran komputer jauh lebih kecil, lebih hemat daya, lebih cepat, dan lebih andal. Bahasa pemrograman tingkat tinggi mulai muncul: FORTRAN (1957), COBOL (1959). Memori menggunakan magnetic core. Digunakan secara luas di bidang bisnis dan industri. Komputer mulai bisa diprogram dengan kode yang lebih mudah dipahami manusia.

🟡 Generasi Ketiga — Integrated Circuit (IC)

1965 – 1971 · IBM System/360, PDP-8

IC (chip) menggabungkan ratusan transistor dalam satu chip kecil. Ukuran komputer semakin mengecil, lebih cepat, dan lebih murah. Sistem operasi (OS) mulai dikembangkan, memungkinkan satu komputer menjalankan banyak program sekaligus (time-sharing). Monitor dan keyboard mulai digunakan sebagai antarmuka. BASIC, Pascal, dan bahasa pemrograman lain berkembang pesat.

🟢 Generasi Keempat — Microprocessor

1971 – Sekarang · Intel 4004, IBM PC, Apple Macintosh

Teknologi VLSI (Very Large Scale Integration) memungkinkan jutaan transistor ditempatkan dalam satu chip microprocessor. Intel 4004 (1971) adalah microprocessor komersial pertama. Komputer pribadi (PC) lahir dan menjadi terjangkau untuk rumah tangga. GUI (Graphical User Interface) dikembangkan oleh Xerox PARC dan dipopulerkan oleh Apple (Macintosh, 1984) dan Microsoft (Windows). Internet berkembang pesat di era ini.

🔵 Generasi Kelima — Kecerdasan Buatan (AI)

Sekarang – Masa Depan

Komputer generasi kelima berbasis AI (Artificial Intelligence), machine learning, dan deep learning. Memiliki kemampuan memproses bahasa alami (NLP), mengenali gambar dan suara, serta belajar dari data. Menggunakan parallel processing (memproses banyak instruksi bersamaan) dan quantum computing (dalam pengembangan). Contoh nyata: asisten virtual (Siri, Alexa), mobil otonom, program catur/Go AI, ChatGPT, dan sistem rekomendasi.

Perbandingan Komponen Utama

03

Tabung Vakum

Komponen Gen. 1. Ukuran bola lampu kecil, menghasilkan panas besar, sering terbakar. Berfungsi sebagai saklar elektronik on/off.

Transistor

Komponen Gen. 2. Ukuran sangat kecil, hemat energi, lebih cepat dari tabung vakum. Ditemukan Bell Labs tahun 1947 oleh Shockley, Bardeen & Brattain.

IC (Chip)

Komponen Gen. 3. Menggabungkan banyak transistor dalam satu chip silikon kecil. Ditemukan oleh Jack Kilby (Texas Instruments) tahun 1958.

Microprocessor

Komponen Gen. 4. "Otak" komputer — CPU lengkap dalam satu chip. Intel 4004 pertama kali (1971). Kini memiliki miliaran transistor dalam satu chip.

AI & Neural Net

Komponen Gen. 5. Jaringan saraf tiruan yang meniru otak manusia. GPU + TPU untuk komputasi paralel masif. Mampu belajar, beradaptasi, dan mengambil keputusan.

Perkembangan Hukum Moore

Gordon Moore (co-founder Intel) menyatakan bahwa jumlah transistor dalam sebuah chip akan berlipat ganda setiap ~2 tahun dengan biaya yang sama. Hukum ini telah berlaku selama 50+ tahun dan mendorong revolusi digital yang kita alami sekarang.
